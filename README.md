# 🤖 AI Frontend Generator

An AI-powered frontend generation and learning system that converts user requirements into multiple frontend designs, provides live previews, and explains the generated code.

The project is designed not only to generate frontend code, but also to help users **understand, analyze, and learn from the generated HTML, CSS, and JavaScript**.

---

## 🚀 Project Overview

Normally, creating a frontend website requires manually writing HTML, CSS, and JavaScript.

Our project simplifies this process using AI.

The user can provide:

- A website prompt
- Existing frontend code
- A combination of prompt and code

The AI then generates **three different frontend designs**.

The user can preview all three designs, select the preferred design, and analyze the selected design using AI.

The system provides:

- Overall website explanation
- HTML explanation
- CSS explanation
- JavaScript explanation
- Important HTML tags
- Important CSS properties
- Important JavaScript concepts

The selected design is stored in MongoDB and can be accessed later through the project history.
